# Dynamic Open Graph Image

A Next.js experiment for generating social preview images with Vercel's OG image utilities.

## Project goal

Learn how applications can render dynamic Open Graph images at request time for richer link previews.

## Features

- Generate an image response from an API route
- Compose a social card with web technologies
- Preview the result in a Next.js application

## Technologies

- **TypeScript**
- **React**
- **Next.js**
- **@vercel/og**

## What I learned

- Generating images at the edge from React-like markup
- Understanding Open Graph metadata workflows
- Working with Next.js API routes
- Designing content for social previews

## Running locally

```bash
npm install
npm run dev
```

## Project status

This is a learning and experimentation repository. It documents the concepts practiced at the time and is not presented as a production-ready application.
